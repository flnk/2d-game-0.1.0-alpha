# Game 123

Невеликий 2D-платформер на **Godot Engine 4.7** (рендерер Forward+).

## Відкриття проєкту

1. Встановіть Godot Engine версії 4.7 або суміснішої.
2. Клонуйте репозиторій або завантажте його ZIP-архів.
3. У Godot Project Manager натисніть **Import** і виберіть файл `project.godot`.
4. Відкрийте проєкт і запустіть головну сцену клавішею **F6** або весь проєкт клавішею **F5**.

## Структура

- `Player/` — сцена та логіка гравця.
- `Mobs/` — сцени й логіка ворогів.
- `MAP ASSETS/` — графічні ресурси рівня.
- `project.godot` — налаштування проєкту.
- `menu.tscn`, `level.tscn` — меню та ігрова сцена.

## Що очищено для GitHub

- Видалено кеш редактора Godot (`.godot/`), тимчасові файли та системні `.DS_Store`.
- Не додано сторонній графічний пакет **32rogues**, ліцензія якого забороняє його повторне розповсюдження.
- Не додано каталог `SOUND/` зі стороннім аудіопакетом; у поточних сценах проєкту посилань на нього не знайдено.
- Коментарі в коді та вбудованих скриптах перекладено з російської українською. Логіку скриптів не змінювали.
